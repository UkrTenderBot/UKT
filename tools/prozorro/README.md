# Prozorro монітор: кабель (ВЕК) і тренажери (ІСП)

Скрипти для автоматичного пошуку закупівель, переможців, планів і контролю власної участі.
Два профілі в `profiles.py`: `cable` (за замовчуванням; ВЕК, ВЕЛЕС, СГГ, КПД) і `isp` (ІСП, ІВТ, ФОП Любченко).
Профіль задається `--profile cable|isp`. Код виходу 2 = Prozorro не відповідав (для контролю справності).

| Файл | Що робить |
|---|---|
| `collect.py OUT.json [статуси] [--profile]` | Кандидати з пошуку prozorro.gov.ua: коди ДК + слова профілю. Статуси через кому, за замовчуванням `active.tendering,active.enquiries`. Поле `_supply` — знайдено за кодом поставки товару (п. 7). |
| `scan.py CANDS.json RESULTS.jsonl WORKDIR [--profile]` | Завантажує документи (docx/doc/pdf/xls/xlsx/rtf/zip), шукає марки/ключові слова, пише JSONL: `hits` (марка → файл → фрагменти), `volumes` (марка → метри з розбивкою за перерізами, з позицій закупівлі або оцінкою з документів), `supply` (поставка товару без робіт). Пропускає ID, вже записані в RESULTS. |
| `winners.py UA-... [UA-...] [--profile]` | Статус, переможці/кандидати (active/pending) з контактами, `rejected` (відхилені — переможець змінився, п. 4), `contracts` (статус і дата підписання — сигнал «зараз купує», п. 2), `bidders` і `own_bids` (участь власних компаній), `competitor`/`own` у кожного award. |
| `potential.py PRICES.json RESULTS.jsonl [--ids]` | Потенціал продажу і пріоритет A/B/C (п. 1): метри × середня ціна переможців за маркою й перерізом із «Ціни учасників». Пороги: ≥ 500 тис. грн — A, ≥ 100 тис. — B; без обсягів — за очікуваною вартістю. |
| `plans.py OUT.json [--profile] [--since РРРР-ММ-ДД]` | Річні плани закупівель без оголошеної закупівлі (п. 8): замовник, бюджет, орієнтовний початок. Якщо пошук планів не відповідає (код 2) — перевірити ендпойнт `https://prozorro.gov.ua/api/search/plans` і виправити скрипт. |
| `watch.py OUT.json --ids UA-...,UA-... [--profile] [--since РРРР-ММ-ДДTГГ:ХХ]` | Контроль власної участі (п. 11): `urgent` — чинні вимоги щодо усунення невідповідностей (milestone «24h», п. 43 Особливостей, постанова КМУ № 1178), рішення щодо власних пропозицій, строки, а також `changes` після `--since` (документи/зміни до ТД, відповіді на питання, скарги, рішення, договори). |
| `prices.py OUT.json [--ids]` | Ціни учасників за метр (лише кабель). |

## Профіль ІСП — лише ДК 021:2015 35740000-3 «Симулятори бойових дій»
Окремий скрипт `isp_monitor.py OUT.json [--statuses ...] [--since РРРР-ММ-ДД] [--ids ...]`: пошук закупівель за CPV 35740000-3,
лише закупівлі з позиціями 357400xx; на виході `tenders` (закупівлі, переможці, відхилені, договори, учасники, own_bids, знижка)
і `prices` (ціна за одиницю кожного учасника по кожній позиції 35740000-3). Плани: `plans.py OUT.json --profile isp`,
контроль участі: `watch.py OUT.json --ids ... --profile isp`.
