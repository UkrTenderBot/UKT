# Prozorro монітор кабелю (АСБл, ААБл, ААШв, АПвЕгаПу)

Скрипти для автоматичного пошуку закупівель і переможців (монтажників).

| Файл | Що робить |
|---|---|
| `collect.py OUT.json [статуси]` | Збирає кандидатів із пошуку prozorro.gov.ua: кабельні коди ДК + текст «кабель» + назви марок. Статуси через кому, за замовчуванням `active.tendering,active.enquiries`. |
| `scan.py CANDS.json RESULTS.jsonl WORKDIR` | Для кожної закупівлі завантажує документи (docx/doc/pdf/xls/xlsx/rtf/zip), шукає марки в тексті, пише JSONL з `hits` (марка → файл → фрагменти). Пропускає ID, вже записані в RESULTS. |
| `winners.py UA-... [UA-...]` | Статус закупівлі та переможці (award active/pending): назва, ЄДРПОУ, сума, контактна особа, телефон, email. |
